JNT601B Scenario Content Editor — OFFLINE (no install)
======================================================

FOR GOVERNMENT / LOCKED PCs (no Node.js)

WHAT YOU NEED
  - This HTML file: Scenario-Content-Editor-OFFLINE.html
  - The handoff JSON file from your colleague (e.g. jnt601b-scenarios-2026-05-21.json)
  - Microsoft Edge or Google Chrome

HOW TO OPEN
  1. Unzip the folder (if you received a zip).
  2. Double-click Scenario-Content-Editor-OFFLINE.html
     (Or right-click → Open with → Edge / Chrome)
  3. If the browser blocks the page, click "Allow" or ask IT to permit local HTML files.

HOW TO EDIT
  1. Click "Import handoff (.json)" and select the JSON file you were sent.
  2. Use the tabs: Function library, Subtasks, Element library, Answer key.
  3. Fix any yellow validation warnings.
  4. Click "Export handoff (.json)" when done.
  5. Email the NEW .json file back (do not rename to .js).

ELEMENT FIRST vs SECOND
  The course randomly shows ONE element list per session.
  Answer key has two columns: correct asset for "first" list vs "second" list.

YOUR COLLEAGUE WILL
  Import your returned JSON into their full project and save to the course.
